# 项目架构说明

> Flutter TodoList 待办事项 App —— MVC 架构设计文档

## 1. 架构总览

本项目采用 **MVC（Model - View - Controller）** 分层架构，职责清晰、低耦合：

```
┌─────────────────────────────────────────────────────────┐
│                       View 层 (UI)                        │
│  views/  (home / edit_todo / category / setting /        │
│          onboarding + widgets/) —— 仅负责展示与交互        │
└───────────────▲──────────────────────┬───────────────────┘
                │ 读取状态/派发动作       │ 监听变化 (Provider)
┌───────────────┴──────────────────────▼───────────────────┐
│                    Controller 层                          │
│  controllers/  (task / category / theme)                  │
│  —— 持有数据、封装业务逻辑、持久化、通知 View 刷新         │
└───────────────▲──────────────────────┬───────────────────┘
                │ 组装/解析              │ 调用
┌───────────────┴──────────────────────▼───────────────────┐
│                      Model 层                             │
│  models/  (todo_model / category_model / constants)       │
│  —— 纯数据实体，含 toJson / fromJson 序列化                │
└─────────────────────────────────────────────────────────┘
                         │
                    utils/ (辅助)
        colors / date_helper / theme —— 配色、日期、主题
```

**数据流**：用户操作 → View 调用 Controller 方法 → Controller 修改 Model 并持久化 → `notifyListeners()` → Provider 通知 View 重建。

```

├── models/                        # M 层：数据模型

│   ├── category_model.dart        # 分类实体
│   └── constants.dart             # 内置分类、主题枚举、默认常量
├── controllers/                   # C 层：业务逻辑与状态
│   ├── task_controller.dart       # 任务增删改查、筛选、搜索、备份/恢复
│   ├── category_controller.dart   # 分类管理（新增/删除/初始化）
│   └── theme_controller.dart      # 深色/跟随系统主题切换
├── views/                         # V 层：界面
│   ├── home.dart                  # 首页（UI1）
│   ├── edit_todo_page.dart        # 新增/编辑任务（UI2）
│   ├── category_page.dart         # 分类管理（UI3）
│   ├── setting_page.dart          # 设置（UI4）
│   ├── onboarding.dart            # 启动页
│   └── widgets/                   # 复用组件
│       ├── app_header.dart        # 蓝色渐变头部 + 统计
│       ├── bottom_nav.dart        # 底部导航（首页/分类/设置）
│       ├── category_filter.dart   # 分类筛选 tab
│       ├── todo_tile.dart         # 任务卡片（复选/编辑/删除/左滑）

    ├── colors.dart                # 全局配色（1:1 还原设计稿）
    ├── date_helper.dart           # 日期/时间格式化、相对日期
    └── theme.dart                 # ThemeData 构建器
```

## 3. 各层职责详解

### 3.1 Model 层
| 文件 | 职责 |
|------|------|
| `todo_model.dart` | `TodoModel`：id / title / note / dueDate / isDone / categoryId / priority（`Priority` 枚举：高/中/低）；提供 `copyWith`、`toJson`、`fromJson` |
| `category_model.dart` | `CategoryModel`：id / name；提供 `toJson`、`fromJson` |
| `constants.dart` | 内置分类（日常/工作/学习）、`AppThemeMode` 枚举、默认分类常量 |

### 3.2 Controller 层（继承 `ChangeNotifier`）
| 文件 | 核心能力 |
|------|----------|
| `task_controller.dart` | `tasks` / `visibleTasks`（按分类+搜索过滤并排序）；`addTask` / `updateTask` / `toggleDone` / `removeTask`；`setFilter` / `setSearch`；`clearDone` / `clearAll`；`backup()` / `restore()`（V1.1 单表备份恢复）；`exportAll()` / `importAll()`（V1.2 全量导出导入：任务+分类，跨平台 JSON）；基于 `shared_preferences` 持久化 |
| `category_controller.dart` | `categories`；`addCategory` / `removeCategory` / `replaceAll`（V1.2 全量导入覆盖）；首次启动注入内置分类 |
| `theme_controller.dart` | `mode`（light/dark/system）；`setMode`；持久化主题选择 |

### 3.3 View 层
- **首页 `home.dart`**：渐变头（今日待办 + 统计）、搜索框、分类筛选、任务列表、新增 FAB、底部导航。
- **编辑页 `edit_todo_page.dart`**：紫色渐变头；名称/备注/截止时间/优先级/分类表单；保存/取消。
- **分类页 `category_page.dart`**：分类列表 + 新增（BottomSheet）+ 删除。
- **设置页 `setting_page.dart`**：外观主题切换、数据导入/导出（V1.2：导出/导入两行独立项）、数据管理（清空已完成/全部）、关于、本地存储提示。
- **启动页 `onboarding.dart`**：引导页，跳转主壳。

### 3.4 状态管理
- 使用 **Provider**（`MultiProvider` 在 `main.dart` 顶层注入三个 Controller）。
- `main.dart` 提供 `AppShell` 作为底部导航容器，通过 `IndexedStack` 切换三个主页面。

## 4. 持久化方案

| 数据 | 存储 Key | 说明 |
|------|----------|------|
| 任务列表 | `todolist.tasks.v2` | `shared_preferences` 存 JSON 字符串列表 |
| 分类列表 | `todolist.categories.v1` | 首次启动注入内置分类 |
| 主题模式 | `todolist.theme.v1` | 存枚举 index |
| 备份文件 | App 文档目录 `*.json` | `path_provider` 导出/导入（V1.1 单表；V1.2 全量任务+分类） |

## 5. 平台支持

- ✅ Web（主力开发平台，`flutter run -d chrome`）
- ✅ Android（已验证 debug / release 构建通过）
- ✅ Windows / Linux（无需 CocoaPods，可直接运行）
- ⚠️ macOS / iOS：当前机器 macOS 12 无法安装满足要求的 CocoaPods，**暂不支持**，待升级系统后启用
