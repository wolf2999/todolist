### 3.1 必需的 PATH 配置（ninja）

Android CMake 需要 `ninja` 在 `PATH` 中。本机 ninja 位于 Android SDK 的 cmake 目录内，已通过以下两种方式之一配置（**二选一即可，当前两者均已生效**）：

**方式 A — 全局（推荐，已写入 `~/.zshrc`）：**
```bash
export PATH="$HOME/Library/Android/sdk/cmake/3.22.1/bin:$PATH"
```

**方式 B — 项目级包装脚本 `android/build_apk.sh`（已附带，无需依赖 zshrc）：**
```bash
#!/usr/bin/env bash
set -e
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
NINJA_DIR="$HOME/Library/Android/sdk/cmake/3.22.1/bin"
[ -x "$NINJA_DIR/ninja" ] && export PATH="$NINJA_DIR:$PATH"
cd "$PROJECT_ROOT"
flutter build apk "$@"
```

## 4. 常用命令

```bash
# 获取依赖
flutter pub get

# 本地静态检查（当前：No issues found）
flutter analyze

# —— Web（主力开发平台）——
flutter run -d chrome --web-port 8080
# 构建产物：build/web

# —— Android ——
# 方式1：直接构建（依赖 ~/.zshrc 的 PATH）
flutter build apk --debug        # 调试包 build/app/outputs/flutter-apk/app-debug.apk
flutter build apk --release      # 发布包 build/app/outputs/flutter-apk/app-release.apk (~23.5MB)

# 方式2：用项目脚本（自带 ninja PATH）
./android/build_apk.sh --release

# 安装到设备/模拟器
adb install build/app/outputs/flutter-apk/app-debug.apk

# —— Windows / Linux（无需 CocoaPods）——
flutter run -d windows
flutter run -d linux
```

## 6. 环境踩坑记录（供参考）

1. **`settings.gradle` 占位符未替换**：模板 `{agpVersion}` / `{kotlinVersion}` 需在 `flutter create` 后由工具替换为具体版本；本机骨架未替换，已手动填为 AGP 8.7.0。
2. **旧 `app/build.gradle` 不兼容 AGP 8**：原 compileSdk 28、`com.android.support.test` 旧依赖已重写为 AGP 8.x 模板。
3. **命令式 `apply plugin` 在 Flutter 3.29 报错**：已改为声明式 `plugins { id "com.android.application"; id "dev.flutter.flutter-gradle-plugin" }`。
4. **NDK 版本冲突**：插件要求 NDK 27，本机仅 26，已用 `sdkmanager "ndk;27.0.12077973"` 安装。
5. **CMake / ninja 缺失**：已装 `cmake;3.22.1`，ninja 随 cmake 包提供，加入 PATH。
6. **`MainActivity` 缺 `android:exported`**：targetSdk 31+ 必须显式声明，已在 `AndroidManifest.xml` 的 `<activity>` 加 `android:exported="true"`。
7. **`.flutter-plugins` 废弃警告**：`settings.gradle` 中手写读取 `.flutter-plugins` 的旧逻辑已删除（改由 `dev.flutter.flutter-plugin-loader` 自动处理）。
8. **Xcode Command Line Tools 缺失**：执行 `xcode-select --install` 安装后，`brew install ninja` 等命令行工具方可正常工作。
