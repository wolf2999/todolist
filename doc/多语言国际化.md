# 多语言国际化（i18n）说明

> 版本：V1.4
> 方案：`easy_localization`（零额外原生依赖，Web / Android / iOS / 桌面通用）

## 1. 现状

- 支持语言：**简体中文（zh-CN）**、**繁体中文（zh-TW）**、**English（en-US）**
- 进入应用时跟随**系统语言**；若系统语言不在支持列表，回退「简体中文」
- 用户在「设置 → 语言」中手动切换后，选择会被记住（`shared_preferences` 自动持久化）
- 语言包格式为 JSON，按语言代码分文件存放

## 2. 目录与文件

```
assets/i18n/
  zh-CN.json     # 简体中文
  zh-TW.json     # 繁体中文
  en.json        # 英文

lib/
  main.dart                      # 用 EasyLocalization 包裹应用，声明支持的语言
  models/constants.dart          # 内置分类 / 优先级的本地化辅助
  views/setting_page.dart        # 设置页「语言」切换卡片
```

`pubspec.yaml` 中已注册资源目录与依赖：

```yaml
dependencies:
  easy_localization: ^3.0.7

flutter:
  assets:
    - assets/i18n/
```

## 3. 初始化配置（main.dart）

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await EasyLocalization.ensureInitialized();
  runApp(
    EasyLocalization(
      supportedLocales: const [
        Locale('zh', 'CN'),
        Locale('zh', 'TW'),
        Locale('en', 'US'),
      ],
      fallbackLocale: const Locale('zh', 'CN'), // 系统语言不支持时回退
      path: 'assets/i18n',
      useOnlyLangCode: false,
      child: const MyApp(),
    ),
  );
}
```

`MaterialApp` 使用由 `EasyLocalization` 提供的 locale 与支持列表（**不要**再硬编码 `locale`）：

```dart
MaterialApp(
  locale: context.locale,
  supportedLocales: context.supportedLocales,
  localizationsDelegates: const [
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
  // ...
)
```

## 4. 语言包文件格式

每个文件是一个 JSON 对象，key 与三份文件保持一致，value 为对应语言文案。
支持占位符（命名参数用 `{name}`）：

```json
// zh-CN.json
{
  "setting": "设置",
  "exportData": "导出数据",
  "exported": "已导出数据",
  "imported": "已导入 {count} 条任务",
  "exportFailed": "导出失败：{msg}"
}
```

```json
// en.json
{
  "setting": "Settings",
  "exportData": "Export Data",
  "exported": "Data exported",
  "imported": "Imported {count} tasks",
  "exportFailed": "Export failed: {msg}"
}
```

> 内置分类（日常/工作/学习）和优先级（高/中/低）也走语言包：分类名通过
> `BuiltInCategories.localizedName(id, name)` 在显示层翻译；优先级通过
> `Priority.label` getter 翻译。用户自建分类 / 任务标题等存储型文本不做翻译。

## 5. 在代码中使用

### 5.1 普通文案（最简单）

任意位置给字符串加 `.tr()` 即可，**无需 BuildContext**：

```dart
Text('setting'.tr())
Text('searchHint'.tr())
```

### 5.2 带参数的文案

必须用具名参数 `namedArgs`（`easy_localization` 的 `args` 是顺序列表，
`namedArgs` 才是 `{key: value}` 的 Map）：

```dart
// 文案定义："已导入 {count} 条任务"
'imported'.tr(namedArgs: {'count': count.toString()})

// 文案定义："导出失败：{msg}"
'exportFailed'.tr(namedArgs: {'msg': '$e'})
```

### 5.3 内置分类名

```dart
Text(BuiltInCategories.localizedName(c.id, c.name))
// id 命中 daily/work/study 时返回翻译，否则返回原始 name（用户自建分类）
```

### 5.4 优先级标签

```dart
Text(priority.label)   // 内部已调用 .tr()
```

### 5.5 日期选择器跟随语言

`showDatePicker` 的 `locale` 传 `context.locale`，让系统日期控件也跟随：

```dart
await showDatePicker(
  context: context,
  locale: context.locale,
  // ...
);
```

### 5.6 切换语言（设置页示例）

```dart
context.setLocale(const Locale('zh', 'CN'));   // 简体中文
context.setLocale(const Locale('zh', 'TW'));   // 繁体中文
context.setLocale(const Locale('en', 'US'));   // 英文
```

设置页 `SettingPage` 已提供三枚 pill（简体中文 / 繁體中文 / English），
点击即切换并自动持久化。

## 6. 修改现有文案

1. 打开 `assets/i18n/zh-CN.json`（及其它语言文件）
2. 找到对应 key，修改 value（**保持 key 不变**，否则代码侧 `.tr()` 取不到值）
3. 同步修改 `zh-TW.json`、`en.json` 的对应 value
4. `flutter pub get` 不需要重跑，热重载即可看到效果（改 JSON 后建议重启）

## 7. 新增一种语言

例如新增「日本語（ja-JP）」：

1. 新建语言包 `assets/i18n/ja-JP.json`，复制 `en.json` 的全部 key，翻译 value
2. 在 `main.dart` 的 `supportedLocales` 增加：
   ```dart
   Locale('ja', 'JP'),
   ```
3. （可选）在 `lib/views/setting_page.dart` 的 `_languages` / `_languageLabels`
   列表中追加对应 `Locale` 与显示名（如 `'日本語'`）
4. 重新构建：`flutter build web --release`（语言包会被自动打包到
   `build/web/assets/assets/i18n/`）

> 新增语言时注意 `fallbackLocale` 仍是 `zh-CN`；若希望系统语言精确匹配，
> 保持 `useOnlyLangCode: false`（区分 `zh-CN` 与 `zh-TW`）。

## 8. 新增一个文案 key（通用流程）

1. 在**三份** JSON 里同步加同一 key，如 `"myNewKey": "..."`
2. 代码里用 `'myNewKey'.tr()` 引用
3. 若带参数：`"myNewKey": "你有 {n} 条"` + `'myNewKey'.tr(namedArgs: {'n': '$n'})`
